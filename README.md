# Stars for Impact · inDrive Hackathon 2026

Clickable prototype by Team Lucky Stars (Impact & Inclusion track).

Rate any ride, and inDrive gives S/ 1 to Juntas Llegamos Más Lejos, its program that helps women in Peru get a driving licence.

- Open: `index.html` (single self-contained file, works offline).
- Not a live inDrive feature. All numbers in the demo are illustrative; program facts are from public sources (jlml.indrive.com).
